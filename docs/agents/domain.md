# Domain Docs

This repository uses a single-context domain-document layout.

Before changing a domain area, read root `CONTEXT.md` and relevant records under `docs/adr/` when they exist. Their absence is not a blocker; create or refine them only when a real vocabulary or durable-decision gap is discovered.

Use established terms consistently in specs, tickets, tests, gates, and evidence. Surface any conflict with an ADR instead of silently overriding it.
