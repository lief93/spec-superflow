# Triage Labels

| Matt workflow role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Management must classify the request. |
| `needs-info` | `needs-info` | A genuine external or user-owned fact is missing. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for the persistent Dev. |
| `ready-for-human` | `ready-for-human` | Requires a human-only action. |
| `wontfix` | `wontfix` | Deliberately not pursued. |

`claimed` and `completed` are local execution states, not triage roles.
