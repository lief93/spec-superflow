# Implementation Tasks

## Interfaces

### Batch 1 -> Batch 2

- **Produces**: `verifyMattVendor(pluginRoot)` - Batch 2 uses the validated,
  provenance-bound Matt source root when it adds the Agent and performs real
  host acceptance.
- **Produces**: `stageMattPlugin(extensionRoot)` - Batch 2 verifies the final
  Agent/router through the same deterministic staging seam used by the VSIX.
- **Produces**: `matt-plugin/provenance.json` inventory and per-file digests -
  Batch 2 binds runtime evidence to the exact packaged source identity.
