# Native device verification

Owned scope: this directory and newly generated `/tmp` runs only. Historical
hosts are read-only inputs. No legacy generator is imported or executed.

Integration inputs: actual Compose `Page.kt`, fully qualified root Composable,
and the generator's actual ETS output. `prepare.py` takes an ETS page containing
`@Entry`, or a component name to import through the host. Generated bytes are
copied unchanged and hashed. Additional generated helpers must be supplied in
the same directory. Behavior expectations will be bound to the fixture source,
never inferred from generated ETS.

Run `python3 prepare.py --help`. Output must be a new directory. Build logs,
command argv/cwd/environment/exit codes, input copies and hashes remain there.
Host environment: en-US, light, font scale 1, density 3.5, 1320x2856 screen;
full-screen content with hidden system bars and zero host padding/insets.

Visual policy, fixed before captures: compare identical 1320x2856 full content
at [0,0,1320,2856] without resizing, image registration, or color correction.
Per-channel MAE <= 8/255 and fraction of pixels whose maximum channel difference
exceeds 24 <= 0.08. This is a declared first-slice tolerance, not a claim of
pixel identity. Settled captures require two successive content crops to have
MAE <= 0.25/255. Keep both frames, full originals, differences and numeric report.
No image files may be opened through an AI image/viewing tool.

Additional geometry gate: pager, action button and each painted indicator must
match source absolute bounds within 3.5px (1vp). Indicator paints are 70x28px,
outer slots 98x56px at density 3.5. Padding-ring and painted-inner clicks are
recorded separately; acceptance compares target behavior to actual Android.
Final paired boundary evidence also includes the adjacent gap midpoint and
one pixel to each side. Harmony replays the exact Android coordinates; ties
are checked against the actual source oracle, not assumed child ordering.
